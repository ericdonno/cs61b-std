# 文字输出格式优化计划

## 问题分析

当前代码库中存在以下文字输出格式问题：

1. **字符串拼接缺乏空格** - 如 `System.out.println("Room:"+numberOfRooms)` 应改为 `System.out.println("Room: " + numberOfRooms)`
2. **调试输出不明确** - Hall.java 中使用 `System.out.println(11111)` 等无意义的数字输出
3. **格式不一致** - 有的地方有空格有的没有，如 `"from"+start+"to"+end`
4. **缺少格式化工具** - 没有统一的日志或格式化工具类

## 优化步骤

### 步骤1：创建日志格式化工具类

创建 `byog/Helper/Logger.java`，提供统一的格式化方法：

```java
package byog.Helper;

public class Logger {
    public static void debug(String format, Object... args) {
        System.out.println("[DEBUG] " + String.format(format, args));
    }

    public static void info(String format, Object... args) {
        System.out.println("[INFO] " + String.format(format, args));
    }

    public static void error(String format, Object... args) {
        System.err.println("[ERROR] " + String.format(format, args));
    }
}
```

### 步骤2：优化 WorldGenerator.java

- 统一使用 `Logger` 类替代 `System.out.println`
- 修复空格问题：`"Room:" + numberOfRooms` → `"Room: %d"` 使用格式化
- 修复调试输出格式：`roomSize+":"+p+" "` → `"Room Size: %d, Position: %s"` 使用格式化

### 步骤3：优化 Hall.java（如需要）

- 移除无意义的数字调试输出（11111, 22222, 33333等）
- 或改为使用 `Logger.debug("Generating path for phase %d", phaseNumber)`
- 修复路径输出格式：`"path len:"+path.size()+" from"+start+"to"+end` → 使用 `Logger.debug("Path length: %d, from %s to %s", path.size(), start, end)`

## 注意事项

1. Hall.java 中的数字调试输出（如 11111, 22222）可能用于标识程序执行到了哪个分支，删除前需确认是否需要
2. 如果这些调试输出有保留价值，可以改为更描述性的日志输出
3. 保持向后兼容性，不改变程序逻辑
4. 不处理 MathTest.java（按用户要求）
