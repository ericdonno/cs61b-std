### 代码结构

```java
/**
 * 处理输入的核心状态机方法
 * @return 下一个游戏状态
 */
private GameState processInput(GameState state, char c, StringBuilder seedStr) {
    switch (state) {
        case MENU:
            if (c == 'n') return GameState.SEED_INPUT;
            else if (c == 'l') {
                if (loadGameState()) {
                    Logger.section("Game started (loaded save).");
                    return GameState.PLAYING;
                }
                return GameState.MENU;
            } else if (c == 'q') return GameState.QUIT;
            return state;

        case SEED_INPUT:
            if (Character.isDigit(c)) {
                seedStr.append(c);
            } else if (c == 's') {
                world = generateWorld(seedStr.toString());
                player = spawnPlayer(this.seed);
                entities.add(player);
                Logger.section("Game started (new game).");
                return GameState.PLAYING;
            }
            return state;

        case PLAYING:
            if (c == ':') return GameState.QUIT_PENDING;
            handlePlayerInput(c);
            return state;

        case QUIT_PENDING:
            if (c == 'q') {
                saveGameState();
                return GameState.QUIT;
            }
            handlePlayerInput(c);
            return GameState.PLAYING;

        default:
            return state;
    }
}
```

## Assumptions & Decisions

1. **返回值设计**：`processInput` 返回下一个状态，由调用者决定如何处理（设置变量或作为返回值）
2. **early return 问题**：`playWithInputString` 在 'q' 输入时需要立即返回帧，在重构后通过检查返回值处理
3. **日志保留**：两个方法中相同的日志调用保持不变
4. **兼容性**：重构后行为保持一致，仅消除重复代码
