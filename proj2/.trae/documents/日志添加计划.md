# 日志添加计划

## 概述
为项目中需要日志记录的地方添加日志输出，统一使用项目现有的 `byog.Helper.Logger` 类。

## 当前状态分析

### 日志框架
- 项目使用自定义 `Logger` 类 (`byog/Helper/Logger.java`)
- 支持方法: `debug()`, `info()`, `error()`, `section()`, `subsection()`

### 已有日志的文件
- `Game.java` - `Logger.error()` 用于无效输入和未绑定按键
- `Player.java` - `Logger.info()` 当 seed 为空时
- `WorldGenerator.java` - 大量使用 `Logger.debug()` 和 `Logger.info()`
- `Hall.java` - 大量使用 `Logger.debug()`

### 需要改进的地方
1. **`SaveLoadManager.java`** - 直接使用 `System.out.println` 而非 Logger
   - 第 47 行: 存档失败信息
   - 第 77 行: 加载失败信息
2. **`Game.java`** - 关键操作缺少日志
   - `saveGameState()` - 缺少保存成功/失败日志
   - `loadGameState()` - 缺少加载成功/失败日志
3. **`Main.java`** - 直接使用 `System.out.println`
   - 第 12 行: 参数错误提示

## 修改计划

### 1. SaveLoadManager.java
**文件**: `byog/Core/SaveLoadManager.java`

**修改**:
- 添加 `import byog.Helper.Logger;`
- 第 47 行: `System.out.println("Save failed: " + e.getMessage());` → `Logger.error("Save failed: %s", e.getMessage());`
- 第 77 行: `System.out.println("Load failed: " + e.getMessage());` → `Logger.error("Load failed: %s", e.getMessage());`
- 可选添加成功日志:
  - `save()` 方法成功时: `Logger.info("Game saved to: %s", filepath);`
  - `load()` 方法成功时: `Logger.info("Game loaded from: %s", filepath);`

### 2. Game.java
**文件**: `byog/Core/Game.java`

**修改**:
- `saveGameState()` 方法添加日志:
  - 保存前: `Logger.info("Saving game...");`
  - 保存后: `Logger.info("Game saved successfully.");`
- `loadGameState()` 方法添加日志:
  - 加载前检查存档不存在: `Logger.info("No save file found.");`
  - 加载成功: `Logger.info("Game loaded successfully.");`

### 3. Main.java (可选，低优先级)
**文件**: `byog/Core/Main.java`

**修改**:
- 添加 `import byog.Helper.Logger;`
- 第 12 行: `System.out.println(...)` → `Logger.info(...)`

## 验证步骤
1. 编译项目确认无错误
2. 运行测试确认日志输出正常
